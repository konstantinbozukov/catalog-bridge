# VA playbook — Quora (v0)

**Adapter:** assisted (engine discovers/drafts later; v0 = manual)

## Account warm-up

1. Complete profile with neutral kitchen/home interests (no affiliate links in bio v0)
2. Answer 5–10 non-promotional kitchen questions over 3–7 days
3. Build credibility before any catalog links

## Before posting

- [ ] Question matches an existing comp page constraint exactly
- [ ] Answer is helpful standalone (not link-only)
- [ ] Catalog bridge URL only — **no Amazon URL**
- [ ] Disclosure included if linking to our site with affiliate intent
- [ ] Log post in `data/post-log.json` (or spreadsheet)

## Answer shape

1. Acknowledge the asker's constraint (space, budget, household)
2. Short recommendation with reasoning (2–3 picks max in prose)
3. “Full comparison with specs: [catalog bridge URL]”
4. Disclosure line

## Rate limits

- Max 2–3 catalog-linked answers per day on a new account
- Space posts across days; never duplicate same link on similar questions same day

## Kill signals

- Answer removed or account warned → pause 7 days, review tone
- Zero clicks after 10+ good-match posts → revisit comp quality or venue fit
